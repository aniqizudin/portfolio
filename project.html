Sitting Posture Detection System

  • Trained the model on a curated dataset of 4,977 images, achieving a mean Average Precision of 89.0% on the test set and 83.8% on the validation set.

  • Optimized the inference pipeline for standard laptops, enabling low-latency performance without requiring specialized hardware.

Plantation Analysis & Feature Extraction System

MATLAB

  • Developed an end-to-end image processing pipeline to automate plant detection and counting in aerial agricultural imagery.
  • Implemented CLAHE (Contrast Limited Adaptive Histogram Equalization) in Lab color space and the Excess Green (ExG) index to isolate vegetation from complex soil backgrounds.
  • Applied K-Means Clustering and Otsu’s Thresholding for segmentation, utilizing the Watershed algorithm to successfully separate and count overlapping plants.
  • Engineered an interactive GUI using MATLAB App Designer to visualize processing stages and compute validation metrics (IoU, Dice Score) and texture analysis (Smoothness, Entropy) in real-time.
